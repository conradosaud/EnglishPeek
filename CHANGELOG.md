# Changelog

## 1.0.0

First public release.

- Hold a key (default F12) to see names in English, in place: quests, objectives, NPCs and titles, nameplates (Blizzard and Plater), zones, subzones, maps, continents, dungeons, items on every screen, world objects, flight points, classes, races, professions and weapon skills.
- Optional English world map art using Map Fix Forever's images (keep that addon disabled).
- `/englishpeek status` self-diagnostics.
- Requires Questie (with QuestieDB).
